# 使用技能

安装并加载 `nue-ui` 技能后，向 Agent 提出使用 NueUI 写界面的需求即可，技能会按以下方式工作。

## 触发场景

- **搭页面**："用 NueUI 搭一个后台管理页面 / 表单 / 弹窗流程"；
- **查用法**："NueButton 怎么传参 / 某个组件有哪些属性"；
- **排查问题**："组件没样式 / 图标不显示 / 对话框不弹 / 日期多了 T...Z"；
- **视觉调整**："改主色 / 暗色模式 / 间距"。

## 技能的工作方式

1. 读 `SKILL.md` 的三条心智模型与编写流程；
2. 按任务路由表按需读取 `references/` 深度文档（选型看 `component-map.md`、拼页面看 `recipes.md`、改外观看 `customize.md`、引入看 `get-started.md`）；
3. 动手前核对**组件文档页**（以在线文档为权威出处）的属性与事件表格。

## 与 nue-ui-dev 的分工

|      | `nue-ui`（本技能）           | `nue-ui-dev`                           |
| ---- | ---------------------------- | -------------------------------------- |
| 场景 | 消费方项目里用现有组件写界面 | NueUI 仓库内开发组件库本身             |
| 范围 | 选型、传参、拼页面、定制样式 | 组件源码、主题 CSS、测试、文档、新组件 |
| 位置 | npm 包 `nue-ui-skill`        | 仓库 `.agents/skills/nue-ui-dev`       |

两个技能按触发描述互斥：目标若为"消费现有组件"，命中 `nue-ui`；目标若为"改组件库源码/加组件"，命中 `nue-ui-dev`。
