# Shadlike 主题

`nue-ui-theme-shadlike` 是 NueUI 的默认主题，视觉语言为 **Shadcn-like**：中性、低饱和、以灰阶层次为主，靠克制的阴影与描边建立结构。

它与 [`nue-ui-theme-glass`](./glass.md) 是**并列可选**关系，不是新旧关系。

> 当前版本：`nue-ui-theme-shadlike@0.13.x`
> 本页右上角的主题开关可以实时切换两个主题，直接对比。

## 设计语言

| 维度     | 值                                                                               |
| -------- | -------------------------------------------------------------------------------- |
| 主色     | **无彩色**（`--nue-brand-hue: 0`，但 primary 色阶饱和为 `s0`，所以呈现为纯灰阶） |
| 圆角     | `0.375rem`（6px）                                                                |
| 层次手段 | 单层浅阴影 `1px 1px 2px` + 1px 描边                                              |
| 浮层     | 半透明底 + 细描边，**不使用 `backdrop-filter`**                                  |
| 密度     | 常规（`padding-df 1rem` · `box-size-df 2.25rem`）                                |
| 字重     | 可用 600–700 表达层级                                                            |

**关键点：shadlike 的主色是灰的。** `--nue-brand-hue: 0` 看似红色，但 primary 色阶引用的是 `--nue-hsl-s0`（饱和 0%），所以 `hsl(0, 0%, l)` 一定是无彩灰。想让 shadlike 带上品牌色，改的是**饱和阶梯**而不只是 hue：

```css
:root {
    --nue-brand-hue: 210;
    /* 仅改 hue 无效：色阶默认 s0（0% 饱和）；需同时放开饱和 */
}
```

## 与 Glass 的对比

| 维度 | **shadlike**                      | Glass（Frostline）                         |
| ---- | --------------------------------- | ------------------------------------------ |
| 主色 | 无彩灰阶（`s0`）                  | 冷灰青 `hue 192 / s38%`                    |
| 浮层 | 半透明 + 细描边                   | 玻璃 `blur 16 / saturate 118%` + 霜边      |
| 层次 | 单层浅阴影 `1px 1px 2px`          | 描边 + 内高光为主，阴影更淡（`0 1px 2px`） |
| 密度 | `padding-df 1rem` · `box 2.25rem` | `0.875rem` · `2rem`（更紧凑）              |
| 字重 | 可用 600–700                      | 最高 500，层级靠字号 + 颜色                |
| 圆角 | `0.375rem`                        | `0.375rem`（**相同**）                     |

完整的 token 数值差异见 [设计系统](./design-tokens.md#两个主题的数值差异)。

## 适合什么场景

| 选 shadlike                  | 选 glass                      |
| ---------------------------- | ----------------------------- |
| 后台系统、控制台、管理端     | 产品官网、落地页              |
| 表单与表格密集，需要长期阅读 | 需要「技术感 / 精密感」的表达 |
| 希望组件退到背景、内容在前   | 希望界面本身参与品牌叙事      |

判断依据不是「哪个好看」，而是**这个界面里内容需要占比多少**。shadlike 把自己压到最低，glass 则要求界面有存在感。

## 使用

```shell
pnpm add nue-ui-theme-shadlike
```

```ts
// main.ts —— 与 glass 二选一，不可同时引入
import 'nue-ui-theme-shadlike/dist/index.css';
```

安装细节、按需引入与图标字体见 [安装与引入](./install.md)；深色模式见 [深色模式](./dark-mode.md)；换主色与微调见 [定制主题](./customize.md)。
