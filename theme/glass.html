Glass 主题（Frostline） ​

nue-ui-theme-glass 是 NueUI 的第二个主题包，视觉语言代号 Frostline（霜线）：结霜的光学玻璃 + 阳极氧化金属面板。

它面向开发工具 / 技术产品的落地页——要的是精确可靠，不是潮流。与 nue-ui-theme-shadlike 是并列可选关系，不是替代。

当前版本：nue-ui-theme-glass@0.2.2 本页右上角的主题开关可以实时切换两个主题，直接对比。

设计语言 ​

整套设计只有两个记忆点：冷青调 与 霜边，其余一律安静。

维度值
色相192（冷灰青）
层次1px 1px 2px 单层阴影
圆角0.375rem（6px）
层次手段1px 结构性描边 + 内高光；阴影仅 0 1px 2px
玻璃blur(16px) saturate(118%)，底色 α0.82 / 0.86

霜边是没有直接用组件库、而是直接看 CSS 就能认出的东西：

css
border: 1px solid var(--nue-glass-border); /* 外冷线：功能性，对比度 ≥3:1 */
box-shadow:
    inset 0 1px 0 hsl(0 0% 100% / 0.55),
    /* 内白线：霜的结晶线 */ 0 1px 2px hsl(192 40% 10% / 0.06); /* 仅用于脱离背景 */

分层不靠阴影堆叠，而靠描边与底色差——这也是它和 shadlike 最本质的区别：shadlike 用柔和投影表达"浮起"，Frostline 用刻线表达"精密"。

与 shadlike 的对比 ​

维度shadlikeGlass（Frostline）
品牌色相--nue-brand-hue: 0（红）192（冷灰青）
层次1px 1px 2px 单层阴影描边 + 内高光为主，阴影仍单层但更淡
圆角0.375rem0.375rem（两主题相同）
玻璃 token无6 个 --nue-glass-*
暗色方向因子cos(pi * switch) * -1calc(switch * 2 - 1)（去掉三角函数）
浮层半透明 + 模糊玻璃（blur 16 / saturate 118%）+ 霜边
密度常规更紧凑（padding 0.875rem / box 2rem）
字体层级可用 600–700依赖字号 + 颜色，字重最高 500

选哪个：

  • 后台系统、表单密集、需要长期阅读 → shadlike 更稳
  • 落地页、产品官网、想表达"技术感/精密感" → glass

安装与启用 ​

shell
pnpm add nue-ui-theme-glass
ts
// main.ts —— 与 shadlike 二选一，不可同时引入
import 'nue-ui-theme-glass/dist/index.css';

⚠️ 两个主题都作用在 :root 与 .nue-* 选择器上，同时引入会互相覆盖。换肤 = 改这一行 import，然后重启 dev server。

安装细节、按需引入（dist/components/<name>.css）与图标字体，见 安装与引入——那里的示例以 shadlike 写成，把包名换成 nue-ui-theme-glass 即可，路径结构完全一致。

玻璃分层 ​

不是所有组件都用玻璃。浮层玻璃化，数据区实底——这是刻意的分层，不是遗漏。

层组件表现
玻璃底（9）overlay dialog drawer dropdown tooltip message confirm prompt popup-pool半透明底 + 霜边
其中施加模糊（7）dialog drawer dropdown tooltip message-node-inner confirm promptbackdrop-filter: var(--nue-glass-blur)
不模糊overlay（仅全屏遮罩）· popup-pool（0×0 挂载容器）全视口模糊是单帧最贵开销
实底（其余 25 个）table calendar date-picker input textarea …不透明，长阅读不累眼

select / date-picker 的下拉浮层复用 .nue-dropdown，因此自动玻璃化。

玻璃效果全部由 6 个变量驱动，组件里不硬编码模糊值：

变量作用
--nue-glass-bg半透明玻璃底
--nue-glass-blur唯一模糊来源
--nue-glass-border结构性描边（功能性，参与 3:1 判定）
--nue-glass-solid退化 / 嵌套实底的唯一落点
--nue-glass-scrim仅 overlay 全屏遮罩
--nue-glass-shadow内高光 + 极淡投影

三条退化路径 ​

玻璃在下列任一条件下会自动退为不透明实底，可读性不受损：

  1. @supports not (backdrop-filter: blur(1px)) —— 浏览器不支持模糊
  2. @media (prefers-reduced-transparency: reduce) —— 仅 Chromium 识别
  3. @media (prefers-contrast: more) —— Safari / Firefox 的等价用户意图

三条路径共用同一组覆写（blur → none、bg → glass-solid、border → border-color），改观感只需改 token，不必逐组件处理。

字体建议 ​

主题包不打包 Web Font，--nue-primary-font-family 仍是系统栈，消费方零字体负担。

但如果想完整呈现设计意图，推荐自托管 IBM Plex Sans（可变 400–500）+ IBM Plex Mono（OFL）：

css
:root {
    --nue-primary-font-family: 'IBM Plex Sans', -apple-system, 'PingFang SC', sans-serif;
}

中文层级不要依赖字重：中文常见字体只有 400 一档，500 会触发浏览器合成粗体（笔画糊）。层级应该由字号、颜色、间距承担；字重只作拉丁增强，并配合 font-synthesis-weight: none 止损。

数据、代码、时间戳使用 --nue-font-mono 与 font-variant-numeric: tabular-nums，正文不变量宽字体。

深色模式 ​

与 shadlike 使用同一个开关，不需要媒体查询、也不使用 color-scheme：

css
:root {
    --nue-dark-switch: 1; /* 0 = 亮色（默认），1 = 暗色 */
}

原理与翻转/固定的区别见 深色模式。

需要注意 Glass 特有的一处：暗色下深文本档只有两级（≈次级 / 主文本）。这是玻璃最坏背景（叠加纯白）压窄可用对比带的必然结果，不是实现缺陷。提亮应该走「字号对比 / 霜边加强」，而不是放开饱和度。

定制 ​

改观感优先改 token，而不是覆盖组件规则：

css
:root {
    /* 换主色相与饱和（默认 192 / 38%） */
    --nue-brand-hue: 210;

    /* 让玻璃更实或更透 */
    --nue-glass-bg: hsl(192 22% 98% / 0.88);

    /* 收敛或加强模糊（硬上限：blur ≤ 24px、saturate ≤ 140%） */
    --nue-glass-blur: blur(12px) saturate(110%);
}

要覆盖单个组件时注意选择器权重：主题的组件规则形如 .nue-container > .nue-main > .nue-content（3 个类），消费方用 .nue-content（1 个类）压不过，需要更具体的选择器。

完整的换主色、单组件微调与样式兜底方法见 定制主题；token 清单见 设计系统（以 shadlike 为基础，Glass 在数值上不同、变量名完全一致）。

已知边界 ​

边界说明
阴影与 backdrop-filter滤镜会把元素渲染成离屏纹理，纹理边界 = border-box，子元素阴影越界部分被丢弃。Glass 通过「面板 padding 20px + 阴影收敛到 16px」保证常规状态完整；贴近滚动边缘时仍会被裁一半，属浏览器语义
.nue-content 是滚动容器0.2.2 起 content 内部滚动、header 与 aside 固定。若你的外壳按其他方式布局，可能出现双层滚动条，见 发布说明
flex 滚动前提自定义布局时，flex 子项默认 min-height: auto 不收缩，只写 overflow: auto 不会滚动，必须同时给 min-height: 0
与 shadlike 互斥两主题作用域相同，不可同时引入
