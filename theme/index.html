主题（Theme） ​

NueUI 组件库本身不携带任何样式：组件的 .vue 只负责渲染 DOM 与挂载类名，所有可见的视觉（颜色、尺寸、圆角、暗色模式）都来自主题包。主题通过 CSS 变量（设计 token）驱动，支持深色模式与深度定制。

因此有两个常见现象及其解释：

  • 组件渲染出来但「没有样式 / 长得很素」→ 主题 CSS 没有引入；
  • 想让组件「好看」→ 改主题包或覆盖 token，而不是改组件源码。

两个主题 ​

目前提供两套并列可选的主题。两者变量名完全一致、选择器作用域相同，所以可以互换；也正因如此，不可同时引入——换肤就是替换那一行 import。

主题视觉语言适合
nue-ui-theme-shadlike 0.13.xShadcn-like：无彩灰阶、单层浅阴影、无模糊后台系统、控制台、表单与表格密集的长阅读界面
nue-ui-theme-glass 0.2.2Frostline：冷灰青、霜边玻璃、更紧凑的密度产品官网、落地页、需要「技术感 / 精密感」的表达

判断依据不是「哪个更好看」，而是这个界面里内容需要占多少比例：shadlike 把自己压到最低让内容在前，glass 则要求界面本身参与品牌叙事。

怎么开始 ​

shell
# 二选一
pnpm add nue-ui-theme-shadlike
pnpm add nue-ui-theme-glass
ts
// main.ts —— 只引其中一个
import 'nue-ui-theme-shadlike/dist/index.css';
// 或
import 'nue-ui-theme-glass/dist/index.css';

完整步骤（按需引入、图标字体、dist/ 结构）见 安装与引入。

章节导航 ​

主题一览（只看某个主题长什么样）

  • Shadlike 主题 — 无彩灰阶的设计语言、适用场景
  • Glass 主题（Frostline） — 冷青调与霜边、玻璃分层、退化路径、字体建议

通用机制（对两个主题都成立）

  • 安装与引入 — 全量 / 按需 / 图标字体 / dist 结构
  • 设计系统（Design Tokens） — token 体系原理 + 两主题数值差异表
  • 深色模式 — --nue-dark-switch 的原理与用法
  • 定制主题 — 换主色、调密度、覆盖单组件
  • 按需引入组件样式 — dist/components/<name>.css 清单与依赖说明

读的顺序建议：先在本页选定主题，读对应主题页了解视觉语言，再进入通用机制页。通用机制页的代码示例以 shadlike 为主线（Glass 的差异在每页显式标出或链接到差异表）。
