**为什么「够用」而不是升到 E2E / 降为结构断言**：

1. **缺陷就在 DOM 落点**：回退链的判据是「同一时刻只渲染哪一档」，`mount` 后的真实 DOM（`.nue-avatar__text` / `.nue-avatar__icon` / `img` / 插槽内容）即可端到端判定，无需真实浏览器。图片**加载失败**由 `img.trigger('error')` 驱动（jsdom 本就不真实加载，`src` 用站内路径），与渲染结果无偏差。
2. **升到 E2E 无增量**：jsdom 不真实解码图片，但本单判据不涉及像素/加载时序；真实浏览器只多「真 404」这一层，不改变模板分支归属，属可省接缝（能高不高低，但不为不存在的不确定性加层）。
3. **降为结构断言会失真**：若只断言「传给 `NueText` 的 props」，会漏掉「类名落点 / 插槽是否被遮蔽 / `<img alt>` 是否透传」这三类正是缺陷所在一层的判据。
4. **不新增 `@vue/test-utils` 之外的依赖**：`avatar.test.ts` 已在 root 依赖内；无 router/store/i18n 需求。

**实现契约（RD 需保持的 DOM 形状，用例据此断言）**：文本档 = `.nue-avatar__text`（`NueText` 输出，类名透传）；图标档 = `.nue-avatar__icon`，其元素为 `NueIcon` 的 `<i class="iconfont icon-<name>">` ⇒ 图标身份用 `icon-<name>` 类断言；图片档 = `.nue-avatar__image`。

## 三、逐条用例（AC-117-1~4，共 6 例）

共用前置：`mount(NueAvatar, { props, slots })`；错误态由 `await wrapper.find('img').trigger('error')` 驱动；无 `src` 场景不触发 `error`。

### AV-117-01 主路径：无插槽 + `alt` → 首字母文本（AC-117-1）

- **步骤**：`mount(NueAvatar, { props: { src: '/a.png', alt: '李四' } })` → `img.trigger('error')`。
- **断言**：
    - `find('img').exists() === false`；
    - `find('.nue-avatar__text').exists() === true`，`.text() === '李四'`（**原样整串，不截取、不去字**）；
    - `.nue-avatar__icon` **不存在**；
    - `emitted('error')` 长度 === 1；根元素 `classes()` 含 `nue-avatar`。

### AV-117-02 异常：`icon` 与 `alt` 同时存在 → icon 胜出；且 icon 优先于默认插槽（AC-117-2 + §三 范围 2 / §五 顺序）

- **段 1**：`{ src: '/a.png', alt: '李四', icon: 'location' }`，无插槽 → `error`。
    - `.nue-avatar__icon` 存在，其 `classes()` 含 **`icon-location`**；
    - `.nue-avatar__text` **不存在**；`img` 不存在；`emitted('error')` 长度 === 1。
- **段 2**：同 props **+ 默认插槽** `<div class="slot-avatar">S</div>` → `error`。
    - `.nue-avatar__icon` 存在且含 `icon-location`；`.nue-avatar__text` 不存在；
    - **`.slot-avatar` 不存在**（命中 icon 即停，插槽不再渲染 ⇒ 兑现文档「图片 > icon > 插槽」）；
    - 根元素 `text().trim() === ''`（不留插槽残影）。

> 段 2 是对 §一「附带缺陷 1（传插槽即忽略 icon）」的回归闸门，虽不单独占 AC 编号，但属 §三 范围 2 的硬要求。

### AV-117-03 边界：`alt` 空串 / 全空白 → 回退到默认插槽（AC-117-3 插槽分支）

- **段 1**：`mount(NueAvatar, { props: { alt: '', src: '' }, slots: { default: '<div class="slot-avatar">S</div>' } })`。
- **段 2**：`alt: '   '`（三个半角空格），其余同段 1。
- **两段一致断言**：`img` 不存在；`.nue-avatar__text` **不存在**（空/空白不算命中）；`.slot-avatar` 存在且 `text() === 'S'`；`.nue-avatar__icon` **不存在**（插槽先于 logo）；`text().trim() === 'S'`。

### AV-117-04 边界：`alt` 空串 / 全空白且无插槽 → `logo` 图标，无空文本节点（AC-117-3 logo 分支）

- **段 1**：`mount(NueAvatar, { props: { alt: '' } })`；**段 2**：`{ props: { alt: '   ' } }`。
- **两段一致断言**：`img` 不存在；`.nue-avatar__text` **不存在**（**不出现空 `.nue-text` 节点**）；`.nue-avatar__icon` 存在且 `classes()` 含 **`icon-logo`**；`text().trim() === ''`。

### AV-117-05 负向闭环：默认插槽与 `alt` 同时存在 → 插槽胜出，`alt` 不顶替（AC-117-4 前半）

- **步骤**：`mount(NueAvatar, { props: { src: '/a.png', alt: '李四' }, slots: { default: '<div class="slot-avatar">A</div>' } })`；先断言图片态，再 `error`。
- **断言**：
    - 图片态：`img` 存在，`attributes('alt') === '李四'`（图片在时不抢文本档）；
    - 错误态：`.slot-avatar` 存在，`text() === 'A'`；`.nue-avatar__text` **不存在**；`.nue-avatar__icon` 不存在；`emitted('error')` 长度 === 1。

### AV-117-06 负向闭环：`<img alt>` 原文透传（含前后空格）+ 无 `src` 也走回退（AC-117-4 后半 + §五「`alt` 语义不变」）

- **段 1（透传逐字符）**：`mount(NueAvatar, { props: { src: '/ok.png', alt: '  李 四 ' } })`。
    - `img` 存在且 `classes()` 含 `nue-avatar__image`；
    - `attributes('alt') === '  李 四 '`（**逐字符相等：不 trim、不改写、不截取**；Vue 对非空串原样写属性）；
    - `attributes('src') === '/ok.png'`；`.nue-avatar__text` / `.nue-avatar__icon` 均不存在。
- **段 2（无图即回退，不必先报错）**：`mount(NueAvatar, { props: { alt: '李四' } })`（`src` 缺省）。
    - `img` 不存在；`.nue-avatar__text` 存在且 `text() === '李四'`；`.nue-avatar__icon` 不存在；`emitted('error')` 为 `undefined`（没有图片就不该 emit）。

1. **`alt` 空串 vs 透传** —— 采纳 QA 理解，PRD §五「`alt` 语义不变」定稿为：渲染 `img` 时**非空 `alt` 逐字符写入**（不 trim、不改写）；`alt=''` 落成 `alt=""`（装饰图语义），**不参与**首字母回退。⇒ 用例不改：AV-117-06 段 1 只断言非空串透传，AV-117-04 覆盖「空串不算命中」。
