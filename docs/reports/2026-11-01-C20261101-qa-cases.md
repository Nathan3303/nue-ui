## 一、验证接缝定稿（QA 结论）

**一行结论**：PM 候选的 3 个既有测试文件全部采纳、接缝数量不增不减；但 **#108 必须装载真实 `vue-router` 实例**（`createRouter` + `createMemoryHistory` + `mount(..., { global: { plugins: [router] } })`），**禁止用 `RouterLinkStub` / 自定义 stub 顶替**。

| 单号 | 接缝（定稿）                                          | 环境                                  | 与 PM 候选的差异                                                       |
| ---- | ----------------------------------------------------- | ------------------------------------- | ---------------------------------------------------------------------- |
| #108 | `packages/components/link/__tests__/link.test.ts`     | jsdom + `mount` + **真实 vue-router** | 文件不变；**新增 root devDependency `vue-router`**（见下「前置条件」） |
| #109 | `packages/components/avatar/__tests__/avatar.test.ts` | jsdom + `mount`                       | 无差异                                                                 |
| #110 | `packages/components/switch/__tests__/switch.test.ts` | jsdom + `mount`                       | 无差异                                                                 |

**为什么 #108 不能省掉真路由**（三条理由，按重要性）：

1. 缺陷机制就是「`href: undefined` 经组件 fallthrough 覆盖 `RouterLink` 自算的 `href`」——stub 不实现 `resolve()`、也不复现 `mergeProps` 落点，**用 stub 测等于测 stub**，修复前后都会「绿」，无法防回归。
2. AC-108-1 的判据是**等值断言**（`href === router.resolve('/x').href`），该期望值只能由真实 router 产生。
3. AC-108-4 的键盘可达性判据（`tabIndex >= 0`、`focus()` 后 `document.activeElement`）依赖真实锚点语义；接缝落在「挂载后 DOM」这一最高层稳定接口，符合「能高不高低」。

**前置条件（需 PM 决策 / 并入 #108 的 PR）**：

- 实测：root 执行 `import('vue-router')` → `ERR_MODULE_NOT_FOUND`；`vue-router` 仅由 `apps/playground` 声明（`^4.4.5`），pnpm store 内已有 `4.6.4`。⇒ 需 `pnpm add -D vue-router@^4.4.5`（**测试基础设施改动，零功能代码**，改 `package.json` + `pnpm-lock.yaml`）。
- 若 PM 否决新增 devDependency：**#108 只能降级为结构断言**（断言传给 router-link 的 props），AC-108-1 的等值判据与 AC-108-4 的 DOM 判据均失去保真度 —— QA 不推荐，且会导致 PRD §七 AC 与本清单不一致（触发 AC8 一致性闸门）。
- 落地注意：装包后若出现双 `vue` 实例（store 内存在 `vue@3.5.41_typescript@5.6.3` 与 `…@5.9.3` 两个副本），优先用 `global.plugins: [router]` 在 app 级注入（而非 `provide` 单点注入），并在文件内 `await router.isReady()` 后再断言。
