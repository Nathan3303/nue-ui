# v1.16.0

**头像没图时能显示名字首字母了，回退顺序也变成文档一直承诺的那一套**：以前 `alt` 写得再对也不生效，现在它会真的顶上来；同时，显式指定的图标不再被默认插槽「吃掉」。

## ✨ 更好用了

### 头像没有图/图坏了，显示姓名首字母

以前给头像写 `alt="李四"`，图片加载失败后看到的是通用占位图标——`alt` 只有在另外写一段插槽内容时才「顺带」生效，等于形同虚设。

现在只要写了 `alt`（且没写插槽），头像位会直接显示「李四」。适合通讯录、登录态头像这类只有名字和图片地址的场景。`alt` 里的前后空格原样保留，不会被改写。

## ⚠️ 请留意

### 头像的回退顺序统一为：图片 → 图标 → 默认插槽 → `alt` 首字母 → 占位图标

这条顺序以前**实现和文档不一致**：文档说图标优先于插槽，实际是插槽优先、而且会忽略你显式传的图标。

有两处用户可见的变化：

- 同时给了 `icon` 和默认插槽时，**以前显示插槽内容，现在显示图标**——因为显式指定图标更符合直觉（也正是文档承诺的行为）。
- 同时给了 `alt` 和默认插槽时，**显示插槽内容，`alt` 不会顶替它**：插槽是你亲手写的内容，`alt` 只是图片的替代文本，不该盖过它。

只传 `alt`、不传插槽的场景不受影响，正是上面新修好的那条。
