# nue-ui-theme-glass v0.2.2 — 滚动契约回归

> **这是一个行为反转版本。** 如果你在 0.2.0 / 0.2.1 上做过「页面级滚动」的适配，升级后滚动条会移到 `.nue-content` 内部。

## 改了什么

| 选择器         | 0.2.1                                                    | **0.2.2**                                     |
| -------------- | -------------------------------------------------------- | --------------------------------------------- |
| `.nue-content` | `overflow: visible`                                      | **`overflow: auto`** + `padding: 0.625rem`    |
| `.nue-aside`   | `overflow: auto`（且下层有一条 `hidden` 被覆盖的死声明） | **`auto`** + `overflow-x: hidden`，死声明已删 |
| `.nue-main`    | 无 `min-height`                                          | **`min-height: 0`**                           |

## 为什么反转

0.2.0 的前身曾把 `.nue-content` 从滚动容器改为 `visible`，理由是：

> 滚动容器会裁掉超出 padding box 的绘制，内部元素阴影无法完整显示。

代价是**滚动职责上移到页面层**——于是 header 与 aside 跟着整个页面一起滚走。在表格、日历这类需要纵向定位的页面里，滚动时「当前在看哪个组件、导航在哪」全部丢失。

0.2.2 把语义拿回来：**`.nue-content` 是滚动区**，header / aside 固定，用 padding 给阴影留空间。

**代价仍然存在，只是被缓解**：content 内元素**贴近滚动边缘**时阴影仍会被裁一半——这是滚动容器的固有行为，padding 只保证非贴边状态完整。不要为此把 `overflow` 改回 `visible`，那会退回 0.2.1 的老问题。

## 升级注意

**这是行为反转，不是纯 bug 修复。**

| 你原来的做法                                                       | 升级后应该改成                                |
| ------------------------------------------------------------------ | --------------------------------------------- |
| 放开外壳高度（`html/body/#app` 与容器 `height: auto`）让**页面滚** | 恢复固定高度（如 `100vh`），让 content 内部滚 |
| 自己在外层建滚动区                                                 | 直接用 `.nue-content`（它现在就是滚动容器）   |

**若不做适配**：会出现「页面滚 + content 滚」的双层滚动条，或者页面不滚而内容被截断——取决于你外壳的高度设定。

## 一个必须知道的实现细节

如果你自己实现滚动布局：**flex 子项的默认 `min-height` 是 `auto`，它不会收缩到内容高度以下**。只写 `overflow: auto` 永远不会触发滚动，必须同时给 flex 子项 `min-height: 0`。

本包已在 `.nue-main` 上处理好，但这条规则对所有自定义布局同样适用。

## playground 实测（CDP，真实滚动与拖拽）

- 1280×900：页面 `scrollHeight 900 = clientHeight 900` **不滚**；content `1168 / 836` 内滚；header 固定 `top=0`
- 拖分隔线（aside 430 → 594px）后：content 仍可滚、页面仍不滚
- 390×844：页面不滚，仅 content 一个滚动容器（无双层滚动条）
- aside 折叠态（0 宽）：可见滚动容器只剩 content
