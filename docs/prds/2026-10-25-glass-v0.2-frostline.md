# Glass v0.2.0 重新设计：Frostline（霜线）

> Issue [#81](https://github.com/Nathan3303/nue-ui/issues/81) · 设计依据：frontend-design skill
> 题材：**开发工具 / 技术产品落地页** · 受众：工程师 · 任务：让人相信这东西精确、可靠、不花哨

## 一、为什么重做

v0.1.0 的 glass 是「shadlike 换皮」：34 个组件文件 90% 结构照抄，只改了值。色板 `hsl(211, 90%)` 是 Apple 系统蓝，玻璃 `saturate(180%)` 把背景色放大成糖水——**客观上读起来是 Apple HIG 的临摹品，不是有自己观点的设计**。

`Apple HIG 玻璃拟态` 同时命中 frontend-design skill 列出的「AI 生成痕迹」清单（SaaS 卡片套件：磨砂白卡 + 大圆角 + 柔和阴影 + 彩色渐变）。所以本次不是"再调一版颜色"，而是换掉整套视觉语言。

## 二、隐喻

**结霜的光学玻璃 + 阳极氧化金属面板。不是果冻，是仪器。**

三个推论：

1. 层次由**线**承担，不是影（仪器靠刻线与分界，不靠投影营造浮空）
2. 玻璃是**霜**不是糖水（低饱和、高不透明、小半径模糊）
3. 颜色克制到近乎无彩，只有一个冷青信号色

## 三、色板（6 个命名色）

| ------------- | ------------------- | --------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| **Ink**       | `#0C1417`           | `hsl(196, 31%, 7%)`                                                                                 | 主文字 / 暗色基底（近黑带青；不用纯黑，也不用模板 `#111`）                                     |
| **Hoarfrost** | `#EDF0F1`           | `hsl(195, 12%, 94%)`                                                                                | 亮色基底（冷白微青；不是暖米 `#F4F1EA`）                                                       |
| **Verdigris** | `#3E7C8A`           | `hsl(191, 38%, 39%)`                                                                                | 品牌主色——青瓷铜绿，像仪表盘指示灯                                                             |
| **Rime**      | `#8FA6AD`           | `hsl(194, 18%, 62%)`                                                                                | 次级文字 / 结构性描边                                                                          |
| **Signal**    | `#4E8C6A`           | `hsl(148, 28%, 43%)`                                                                                | 成功态                                                                                         |
| **Ember**     | `#A8453C`           | `hsl(5, 47%, 45%)`                                                                                  | 错误态——**唯一用于强调/装饰的暖色**                                                            |
| **Amber**     | `hsl(30, 68%, 38%)` | 基准色（文字/描边）；**实心填充用 `hsl(30, 68%, 30%)`**（白字 7.03:1；38% 作填充仅 4.91，余量过薄） | 警告态。**状态色不受「唯一暖色」约束**：用户必须一眼区分「警告」与「错误」，功能优先于色彩纪律 |

**统一色相 `192`**（196~191 取中）；主色饱和 **38%**（v0.1 是 90%）。

### 色阶派生规则

11 档 primary（`0 / 100 … 1000`），亮色模式目标：

| 档      | 0   | 100 | 200 | 300 | 400 | 500 | 600 | 700 | 800 | 900 | 1000 |
| ------- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | ---- |
| L（亮） | 99% | 96% | 92% | 86% | 76% | 60% | 44% | 32% | 22% | 15% | 8%   |
| L（暗） | 8%  | 11% | 14% | 18% | 24% | 40% | 40% | 68% | 78% | 85% | 92%  |
| S       | 20% | 18% | 16% | 14% | 16% | 22% | 32% | 38% | 40% | 42% | 45%  |

暗色模式：亮色端**一律不动**；暗色端从 8% 起按 `ΔL ≥ 1.5%` 重排（#95：旧口径「`≈ 100 − L` 后夹紧 10% / 92%」会把 0 / 100 / 200 三档压成同色）；S 略降（−4~−8%）。600 两模式固定 40%（白字对比度，见 RF-1）。

**语义映射**：

- `600` = 实心填充（配白字）
- `700` = 主文本（亮色模式）/ 次级文本（暗色模式）
- `800` = 主文本（暗色模式）
- 语义填充色（success/warning/error）**两模式固定不翻转**（翻转后白字对比度会崩）

> 具体 l 阶梯函数由实施方按现有 `calc(N% ± switch*X%)` 结构反推，端点必须命中上表**两行**；对比度是最终裁判。暗色端的中间档 l95 / l85 / l75 同样按 `ΔL ≥ 1.5%` 内插（9.5 / 12.5 / 16）。

## 四、类型系统

| 角色                        | 字族                                                                                                  | 说明                                  |
| --------------------------- | ----------------------------------------------------------------------------------------------------- | ------------------------------------- |
| UI / 正文                   | `-apple-system, 'PingFang SC', 'Noto Sans SC', …`（沿用）                                             | 字重只用 **400 / 500**，禁止 700 粗黑 |
| 数据 / 代码 / 标识符 / 数字 | 新增 `--nue-font-mono`：`ui-monospace, SFMono-Regular, Menlo, Consolas, 'Liberation Mono', monospace` | 题材正当，不是装饰                    |

- base 16px（`--nue-primary-font-size-base`），组件密度用 `--nue-text-sm`（14px）
- 标题字距 `-0.01em`；等宽标签字距 `+0.02em`
- 数字统一 `font-variant-numeric: tabular-nums`（表格数字对齐是仪器感的一部分）

**变量新增**：本轮**放开**「只许新增 `--nue-glass-*`」的限制——允许新增 `--nue-font-mono`。理由：设计系统需要，且新增变量名不影响组件（组件只要求变量**存在**）。`--nue-glass-*` 仍限定 6 基元。

### 字体策略（重要）

**主题包不打包 Web Font**，`--nue-primary-font-family` 仍为系统栈（消费方零字体负担）。但推荐消费方自托管 **IBM Plex Sans（可变 400–500）+ IBM Plex Mono**（OFL）：

- Poppins 一类几何圆体与大 x-height 的字体，与 PingFang 并排是「两种字体硬拼」，气质偏消费级 SaaS——与本题材相悖
- 仅切 400 字重却在 UI 里声明 500 → 浏览器**合成粗体**，笔画糊；`font-synthesis-weight: none` 可止损但不能替代真字重

**CJK 现实约束**：中文常见字体只有 400 一档（或切片后只有 400）。因此：

- **层级不得依赖 500**（字号 + 颜色 + 间距才是 CJK 层级的主手段）
- 500 只作**拉丁增强**，缺失时不得导致视觉降级
- playground 演示壳已按此接入 IBM Plex，作为「设计意图的参照」；主题包本身仍交付系统栈

## 五、空间与层次

| 项       | v0.1（Apple 临摹）                       | v0.2 Frostline                                     |
| -------- | ---------------------------------------- | -------------------------------------------------- |
| 圆角     | `--nue-primary-radius: 0.625rem`（10px） | **`0.375rem`（6px）**；sm 0.25 / df 0.375 / lg 0.5 |
| 层次手段 | 多层阴影                                 | **1px 结构性描边 + 内高光**；阴影近乎为零          |
| 内边距   | padding-df 1rem                          | **0.875rem**；sm 0.625 / xs 0.375                  |
| 间距     | gap-df 1rem                              | **0.75rem**（密度更高）                            |
| 盒子高度 | box-size-df 2.25rem                      | **2rem**（更紧凑）                                 |
| 阴影     | `0 1px 2px + 0 4px 12px`                 | **`0 1px 2px`（仅此一层）**                        |

### 唯一的记忆点：霜边

```css
/* 外描边：功能性，对比度 ≥3:1 */
border: 1px solid var(--nue-glass-border);
/* 内高光：霜的结晶线 */
box-shadow:
    inset 0 1px 0 hsl(0 0% 100% / 0.55),
    0 1px 2px hsl(192 40% 10% / 0.06);
```

除霜边外**一切安静**：无渐变装饰、无彩色光晕、无入场动画。

## 七、组件派生规则（批 2 照此执行）

1. **不再逐文件对照 shadlike 改值**：每个组件先问「它属于哪种表面」，再套用表面规则
    - 表面 A（实底）：`primary-color-0` 底 + `border-color` 描边 + `0 1px 2px` 影
    - 表面 B（玻璃）：6 个 glass 基元
    - 表面 C（实心填充）：`600` 底 + 白字，无阴影
2. **强调用描边不用影**：hover/active 优先改边框色与底色，不改阴影
3. **等宽只在表现数据处出现**：数字、ID、代码、时间戳、计数
4. **焦点态**：`border-color: 600` + `box-shadow: 0 0 0 2px hsl(192 38% 44% / 0.28)`（2px 环，比 v0.1 的 12px 光晕更锐利）

## 八、验收标准

| ID    | 判据                                                                                                                                                             |
| ----- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AC-01 | 34 组件全部派生自新系统，无残留 v0.1 的 `hsl(211…)` / `saturate(180%)`                                                                                           |
