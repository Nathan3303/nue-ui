# PRD：NueUI Glass 主题包（`nue-ui-theme-glass`）

| 项        | 内容                                                   |
| --------- | ------------------------------------------------------ |
| 日期      | 2026-10-25                                             |
| 状态      | 已开工（T75-1 架构评审通过，待派发 T75-2）             |
| 提议/归属 | 用户提出 → PM 立项                                     |
| 目标版本  | `nue-ui-theme-glass@0.1.0`（独立 SemVer，不跟随 core） |
| 关联      | 现有唯一主题 `nue-ui-theme-shadlike@0.13.28`           |

**TL;DR**：新增一个纯 CSS 主题包，对标 Apple HIG 玻璃拟态，服务 **C 端官网/落地页**；与 shadlike 同构、同 token 契约、同构建方式，**34 个组件样式全量覆盖**，亮/暗双套，浮层玻璃化 + 数据区实底分层，并带对比度/退化自检门禁。

> ⚠️ 本文档只定**业务目标、边界、规则与验收**。具体实现路径（tokens 数值体系、backdrop 采样参数、构建接线细节）由 `arch-designer` 出技术方案后回填 §六 技术指标。

## 一、问题证据

| #   | 证据                                                                                                                                      | 结论                                                       |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |

| E3  | 用户本次明确提出「实现一个新的主题包」，并定档 **C 端官网/落地页 + Apple HIG 玻璃拟态 + 全量对齐**                                        | 需求真实、边界由用户拍定，非 PM 推测                       |
| E4  | 消费方接入方式为一行 `import '…/src/index.css'`（见 `apps/playground/src/main.ts`）                                                       | 一个包天然支持「换一行即换肤」                             |

## 五、业务规则

| ID  | 规则                                  | 说明                                                                                                                                                                                                                                                                                                                        |
| --- | ------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R1  | **Token 契约不可破**                  | 组件通过 `--nue-*` 变量取样式；glass 必须提供与 shadlike **同名**的全部变量（可新增 `--nue-glass-*` 专属变量），禁改名/删名                                                                                                                                                                                                 |
| R2  | **主色系统蓝**                        | `--nue-brand-hue: 211`（#007AFF 系），语义色 hue 沿用 shadlike（success 120 / warning 30 / error 10）                                                                                                                                                                                                                       |
| R3  | **双模式同构**                        | 沿用 `--nue-dark-switch`（0/1）驱动的色阶翻转机制，默认亮色；不做 media query                                                                                                                                                                                                                                               |
| R4  | **分层策略：浮层玻璃底 / 数据区实底** | 玻璃底 9 个：`overlay`（仅半透明 scrim，**不模糊**）`dialog` `drawer` `dropdown` `tooltip` `message` `confirm` `prompt` `popup-pool`（0×0 容器）；其中施加 `backdrop-filter` 的**模糊面 = 7**（排除 overlay / popup-pool）。其余 25 个 → 实底不透明（`select` / `date-picker` 浮层由 `dropdown.css` 玻璃化，自身 0 条模糊） |
| R5  | **玻璃 token：3 主 + 3 辅助**         | 模糊**只由** `--nue-glass-blur` 驱动；底色 `--nue-glass-bg`；描边 `--nue-glass-border`；辅助：`--nue-glass-solid`（退化/嵌套的唯一落点）、`--nue-glass-scrim`（遮罩）、`--nue-glass-shadow`（浮层投影）。组件不得硬编码模糊/透明度数值                                                                                      |
| R6  | **三条退化路径（同构、单点覆写）**    | ① `@supports not (backdrop-filter: blur(1px))`；② `@media (prefers-reduced-transparency: reduce)`（仅 Chromium 识别）；③ `@media (prefers-contrast: more)`（Safari/Firefox 的等价意图）。三条共用同一组 3 条覆写：blur→`none`、bg→`var(--nue-glass-solid)`、border→`var(--nue-border-color)`；退化后必须仍满足 AC-08        |
| R7  | **对比度按最坏背景算**                | 玻璃层文本对比度按「叠加在最亮/最暗背景之上」的合成结果实算，不得只在纯白/纯黑上验证                                                                                                                                                                                                                                        |
| R8  | **圆角放大**                          | HIG 连续圆角：`--nue-primary-radius` 0.375rem → 0.625rem，`radius-sm/df/lg` 同步成梯度（具体数值待 arch 定）                                                                                                                                                                                                                |
| R9  | **阴影柔和多层**                      | 用多层低透明度阴影替代 shadlike 的 `1px 1px 2px` 硬阴影                                                                                                                                                                                                                                                                     |
| R10 | **字体不改栈**                        | 沿用现有系统字体栈（已含 `-apple-system`/`PingFang SC`），不引入 Web Font                                                                                                                                                                                                                                                   |
| R11 | **构建产物路径一致**                  | `dist/` 结构与 shadlike 相同（`dist/index.css` + `dist/components/*` + `dist/global/*`），`exports: "./dist/"`                                                                                                                                                                                                              |
| R12 | **不污染 shadlike**                   | 所有 selector 作用域与 shadlike 相同（`:root` 与 `.nue-*`），二者不可同时引用；README 必须写明「二选一」                                                                                                                                                                                                                    |

## 六、NFRs（业务视角基线，技术指标由 arch 转译回执）

| 维度     | 基线要求                                                                                                                                                                                                                                                                                                         |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 可访问性 | WCAG 2.1 AA：文本 ≥4.5:1、非文本 ≥3:1；支持 `prefers-reduced-transparency`；键盘焦点可见（focus ring 不得被玻璃底吞掉）                                                                                                                                                                                          |
| 性能     | 模糊面 **7** 个类名（dialog/drawer/dropdown/tooltip/message-inner/confirm/prompt）；`blur` ≤ 24px（默认 20px）、`saturate` ≤ 200%（默认 180%）；同一叠加链 ≤ 1 层、同屏同时可见 ≤ 2 层、全视口面积模糊 = 0；`will-change` 与模糊动画各 0 处；`dist` ≤ 125,000 B（gzip ≤ 16,000 B、单文件 ≤ 10,000 B、文件数 41） |
| 兼容性   | `backdrop-filter` 不支持时退化（AC-06）；`prefers-reduced-transparency`（仅 Chromium）与 `prefers-contrast: more`（Safari/Firefox 等价意图）双触发退化（AC-07/17）；glass **零**现代颜色/三角语法（AC-16），不依赖浏览器版本矩阵；不引入 JS 依赖                                                                 |
| 可维护性 | 目录结构与 shadlike 一一对应，便于 diff 对照与后续同步；变量集中定义，组件只做映射                                                                                                                                                                                                                               |
| 构建     | `pnpm build` 无告警；`check:lf` 通过；不新增构建工具链（沿用 postcss + cssnano）                                                                                                                                                                                                                                 |
| 可升级性 | token 数值调整不影响组件样式文件；新增组件时可增量补样式而不改已有文件                                                                                                                                                                                                                                           |

## 七、验收标准（AC）

| ID    | 覆盖类     | Given                                                                  | When                                                                                   | Then                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ----- | ---------- | ---------------------------------------------------------------------- | -------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AC-01 | 主路径     | 干净工作区                                                             | 执行 `pnpm --filter nue-ui-theme-glass build`                                          | 产出 `dist/index.css`、`dist/global/*`、`dist/components/*`（34 个），退出码 0                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| AC-02 | 主路径     | playground 引用 glass 主题                                             | 启动 playground 逐个打开组件文档页                                                     | 34 个组件全部呈 glass 风格，无「没被主题覆盖」的裸样式组件                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| AC-03 | 主路径     | 任意组件                                                               | 将 `--nue-dark-switch` 从 0 切到 1                                                     | 整套变暗，无残留亮色硬编码块；再切回 0 复原                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| AC-04 | 主路径     | —                                                                      | 检查主色令牌                                                                           | `--nue-primary-color-500` 落在 hue 211 系（系统蓝），primary 色阶亮暗两套均可辨                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| AC-05 | 主路径     | 打开 dialog / drawer / dropdown / tooltip / message / confirm / prompt | 观察浮层                                                                               | `dist` 中 `backdrop-filter` 声明**恰好 7 条**（dialog / drawer / dropdown / tooltip / message-inner / confirm / prompt），值均为 `var(--nue-glass-blur)`；`overlay`、`popup-pool` = **0** 条；`blur` ≤ 24px、`saturate` ≤ 200%；背景可透出、描边来自 `--nue-glass-border`                                                                                                                                                                                                                                                                                         |
| AC-06 | 异常       | 模拟不支持 `backdrop-filter`                                           | 跑退化断言                                                                             | ①退化块存在 1 个、含 3 条覆写（blur→`none` / bg→`var(--nue-glass-solid)` / border→`var(--nue-border-color)`）；②覆写值无 alpha；③块位置在基值声明之后；④退化态重算对比度：文本 ≥4.5:1、功能性边框 ≥3:1                                                                                                                                                                                                                                                                                                                                                            |
| AC-07 | 异常       | 模拟 `prefers-reduced-transparency: reduce`                            | 跑退化断言                                                                             | 与 AC-06 同构；注明该媒体特性**仅 Chromium 识别**，Safari/Firefox 忽略即不退化，可读性由 AC-09 兜底                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| AC-17 | 异常       | 模拟 `prefers-contrast: more`（Safari/Firefox 的等价用户意图）         | 跑退化断言                                                                             | 第三条退化块存在，复用同一组 3 条覆写，断言与 AC-06 同构                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| AC-08 | 边界       | 亮色与暗色两套                                                         | 跑对比度单测                                                                           | 文本 ≥4.5:1、非文本 ≥3:1；非文本仅覆盖**功能性边框与语义配对**，`--nue-divider-color`（分隔线）与 `--nue-glass-border`（装饰高光）豁免；受测配对总数 ≥ **80**（28 文本 + 28 边框 + 24 语义配对）；无快照兜底（改低对比即失败）                                                                                                                                                                                                                                                                                                                                    |
| AC-09 | 边界       | 玻璃层叠加纯白与纯黑两种极端背景                                       | 实算合成对比度                                                                         | 按 `--nue-glass-bg` alpha（亮 0.76 / 暗 0.80）合成；最坏值：文本 ≥4.5:1（实测 7.19 / 7.32）、功能性边框 ≥3:1（实测 3.39 / 4.28）                                                                                                                                                                                                                                                                                                                                                                                                                                  |

| AC-11 | 负向闭环   | 切回 shadlike（同机、同页面）                                          | 重启 dev server 后查看                                                                 | 不残留 glass 样式（无历史样式泄漏），两包不可同时引用已在 README 声明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| AC-12 | 设计一致性 | —                                                                      | ①主门禁：对比 `global/variables.css` 定义名；②增量门禁：对每个已存在的组件文件逐一对比 | ①glass 全局定义名 ⊇ shadlike 同文件 **143** + 6 个 `--nue-glass-*` = **149**，新增名仅 `^--nue-glass-`；②每个已存在组件文件：`defined ⊆ defined(shadlike:同文件) ∪ {^--nue-glass-*}`，**且**其中出现的每个 `--nue-glass-*` 必须 ∈ 6 基元白名单 `{bg, blur, border, solid, scrim, shadow}`（**不得发明第 7 个**，否则可自造 `--nue-glass-my-blur: blur(40px)` 绕过 §4.2 半径上限与 R5）；非 glass 局部名禁改名，无害删除放行；配合 M4（引用悬空 = 0）。批 1 覆盖 9 个浮层文件，批 2 自动扩到 34 文件 / **276** 个组件层名；全 src **418** = 143 + 276 − 1 同名交集 |
